# 🚗 TypeScript Vehicle Implementation

## 📜 Description

This project demonstrates TypeScript's capabilities by defining an interface and implementing a class. The task involves a `Vehicle` interface and a `Car` class that implements it. This project showcases basic principles of object-oriented programming and interface implementation in TypeScript. ⚙️

## ⚡ Features

- 🚗 `Vehicle` interface with `make`, `model`, `year`, and a `start` method.
- 🚘 `Car` class implementing the `Vehicle` interface.
- 🔧 TypeScript for type safety and object-oriented design.

## 🛠️ Usage
- 🛠️ The Vehicle interface defines the blueprint for a vehicle.
- 🚗 The Car class implements this interface with a custom start method.
